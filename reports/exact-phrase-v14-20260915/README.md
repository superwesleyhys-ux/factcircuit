# 原文逐项溯源：Astra 与附加溯源指导词

真实调用已完成。两组对三个原文项目都找到了 NASA 公告，区分了实际测量值、成功门槛和条件词。**最终标签相同，没有证明 Harness 的事实正确率更高。** 本轮实现并验证的是“原文位置 → 前后文 → 单项取证 → 原句核验”，不再先生成研究摘要。

## 数据与对比条件

事件是 2022 年 DART 小行星任务的轨道变化通报。输入为 [Axios 原始新闻](https://www.axios.com/2022/10/11/nasa-dart-asteroid-deflection)的 2023-06-06 存档；其正文实际链接到 [NASA 原始公告](https://www.nasa.gov/press-release/nasa-confirms-dart-mission-impact-changed-asteroid-s-motion-in-space)。NASA 旧网址通过已验证的历史跳转到 2024-12-18 存档。截止时间为 2024-12-31。没有付费全文、会员绕过或后验真假标签。

两份原始 HTML 字节均留存并校验。新提取器保存文本节点原有空白，解码 HTML 实体，声明性地加入段落换行和表格单元格制表符；所有位置指向这一存储文本，**不是 HTML 字节位置或网页视觉位置**。Axios 提取文本 2,881 字符，NASA 18,228 字符，完整正文未压缩成摘要。

两组均为 `gpt-6-astra`、low reasoning，经本地 Codex 登录通道执行；模型推理仍在远端。两组每个项目的首次输入完全相同，均有最多 3 次调用、4 次文档尝试、相同文档容量和来源池。每项重新开始，不继承前一项结论。唯一比较变量是附加溯源指导词。

这是**同一个真实事件、三个相关项目、固定两份历史文档的受控回放**。模型实际选择并打开原文链接，模型调用真实发生；本轮未启用开放搜索，也没有独立观测数据。基线同样使用公共提取器、检索执行器和引用验证器，所以它比较的是该执行器内的指导词效果，不是完整 Harness 与无任何包装的裸模型。开发者事前读过材料，本轮不是未见过的准确率留出测试，也不是提前识别 2025–2026 年造假的预测测试。

冻结记录：[协议](../../experiments/exact-phrase-v14-20260915/PROTOCOL.md)、[注册文件](../../experiments/exact-phrase-v14-20260915/REGISTRATION.json)、[原文选择位置](../../experiments/exact-phrase-v14-20260915/INPUT.json)。模型运行期间未改数据、指导词或评分标准。

## 逐项结果

| 原文项目 | 两组都正确保留的上下文含义 | 直接 Astra | Astra + 溯源指导词 |
| --- | --- | --- | --- |
| `32 minutes` | 公告报告的轨道周期缩短量，约 ±2 分钟不确定性 | 公告表述得到支持 | 公告表述得到支持 |
| 门槛句中的 `if` | 条件：达到何种变化可算成功 | 条件标准得到支持 | 限定为 NASA 声明的条件标准 |
| `73 seconds` | 最低成功门槛，包含 73 秒，不是实测变化量 | 门槛标准得到支持 | 限定为 NASA 声明的门槛标准 |

两组都引用了 NASA 真正的门槛句。该句没有字面 `if`；两组均未挪用 NASA 其他段落中不相关的同名词。这说明“原词完全相同”和“原句含义相关”被分开核查，不能把词匹配本身当作事实支持。

直接 Astra 在后两项用了较宽的 `empirical_claim` / `independent_record` 标签；其理由仍明确讨论声明的成功标准，并未声称实际偏转已经独立认证。Harness 对三项均限定为 `source_statement`。独立复核认为这是结论边界的差异，**不能只因标签更保守就把原始 Astra 判错，或宣称准确率获胜**。

Harness 还指出，公告关于轨道周期的测量段落并未单独证实新闻中“太空望远镜”的附加描述。但 NASA 全文确实提到 Hubble 碎片图像和 LICIACube 图像分析，不能把这一限定扩大成“NASA 只用了地面望远镜”。

## 目标逐项验收

| 要求 | 已验证的实现与证据 |
| --- | --- |
| 不用 summary 改写证据 | 新 `trace-phrases` 路径不调用 research/synthesis；12 次调用均收到完整原始提取文本，无前序模型摘要字段。 |
| 单字、词、短语提取 | 精确子串或指定位置，保留重复出现项；单字/词 `if` 和两个数字短语真实跑通。 |
| 关联前后词语 | 每项有原文哈希、起止位置、before/after/context 和完整正文；引用位置由程序核算。 |
| 单项溯源 | 每项独立检索与判断，跟随实际链接及已验证跳转，记录不可访问或证据不足，禁止继承前项结论。 |
| 找出公平对比条件 | 同模型、原文、位置、执行器、权限、上限、输出格式；只改变溯源指导词。实际消耗如实单列。 |
| 可信性边界 | 词匹配、声明归属、经验事实分开；模型判断与机械引用校验分开；缺证不能成为已验证事实。 |

新功能用法见 [逐项溯源说明](../../docs/literal-phrase-tracing.md)。这些检查证明了文本传递和溯源记录的可核查性，**不保证每个模型判断都真、不认证底层科学数据，也不证明通用准确率提升**。后续若要比较准确率，仍需新的独立事件、明确参考标准及开放检索条件，不能反复调这三个项目直到某一组赢。
