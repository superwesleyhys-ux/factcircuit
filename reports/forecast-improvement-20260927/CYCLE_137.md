# Cycle 137 — partial fallback to Astra

The user requested a partial rather than all-or-nothing fallback. `judgment_router.partial_fallback` now returns both the final probability and the fraction of Circuit used. It leaves the frozen Astra/Circuit forecasters and the old hard router unchanged. The intended input remains an independent, outcome-blind subjective probability interval `[l,h]` elicited from the issue-time evidence packet before either arm's forecast is shown to the judge.

Let Astra forecast `a`, Circuit forecast `c`, and final probability `p=a+w(c-a)` for `0≤w≤1`. For binary Brier loss and true conditional event probability `q`, the expected loss difference from Astra is `(p-a)(p+a-2q)`. If `c>a`, the least favorable `q` for moving upward is the interval's lower endpoint `l`, so choose `p=clip(l,a,c)`. If `c<a`, the least favorable `q` for moving downward is the upper endpoint `h`, so choose `p=clip(h,c,a)`. Therefore `w=(p-a)/(c-a)`; equal forecasts or missing judgment use `w=0`. This is the amount of Circuit that minimizes expected Brier loss at the adverse interval endpoint. It improves or ties Astra's **expected** Brier loss for every `q` inside the supplied interval. It does not guarantee a better score for the realized binary outcome, nor that the subjective interval contains the actual event probability.

Example: `a=.03`, `c=.04`, `[l,h]=[.032,.06]` gives `p=.032`, `w=.2`. The hard router from cycle 136 would use Astra because `.032` does not exceed the full-switch threshold `.035`. The new rule takes only 20% of Circuit's change. A lower bound at or below `.03` gives no shift; at or above `.04` gives the full Circuit forecast. The rule is symmetric for downward Circuit adjustments.

The exposed cycle-135 cases **cannot measure this policy's accuracy**: no independent pre-outcome interval exists. On those records the program's missing-judgment branch gives exactly Astra's old four-case Brier `.47573125`, with zero apparent gain. Fabricating intervals from already known outcomes would give an invalid oracle comparison. In the only Circuit-winning case, the later image-overlap reason was absent from the forecast rationale, so a plausible subjective interval need not favor Circuit. For the two Astra wins, unjustified upward movement would worsen the realized score. This makes interval calibration and source-specific causal relevance the limiting work, not the blend arithmetic.
